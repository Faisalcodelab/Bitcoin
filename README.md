💰 Crypto Currency
A Crypto Currency website providing users with a glimpse into the world of Bitcoin, cryptocurrencies, and resources to explore more about these topics.

🚀 Features
Interactive Panels: Click to expand on Bitcoin and cryptocurrency-related topics.
External Links: Links to well-known resources for learning more about Bitcoin and cryptocurrencies.

🎮 How to Use
Open the website in your browser.
Click on any of the panels to explore more about Bitcoin and cryptocurrencies.
Each panel contains a link that will open in a new tab, providing detailed information on the topic.

🛠️ Technologies Used
HTML – Structure for the panels and the overall content of the website.
CSS – Styling for the interactive panels and background images.
JavaScript – Script for controlling the interactivity (e.g., clicking on the panels).
